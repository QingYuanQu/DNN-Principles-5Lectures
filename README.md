# DNN-Principles-5Lectures

深度神经网络基本原理（五讲）—— 从道家哲学视角理解深度学习

## 📖 项目简介

本项目是一套系统性的深度学习教程，通过中国传统哲学"道生一，一生二，二生三，三生万物"的思想框架，深入浅出地讲解深度神经网络的基本原理。从最基础的线性回归开始，逐步深入到多层神经网络，帮助学习者建立对深度学习的直观理解。

## 🎯 课程特色

- **哲学与技术的融合**：用道家思想串联神经网络的发展脉络
- **从简到繁的渐进式学习**：从单一分类到多分类，从单层到多层
- **理论与实践并重**：每个概念都配有详细的数学推导和代码实现
- **可视化教学**：大量图表帮助理解抽象概念

## 📚 课程大纲

### 第0章 - 道·数据

**核心内容**：数据的基础知识
- 数值的统计学概念（平均值、方差、标准差）
- 数据的标准化处理（Z-Score规范化）
- 离差与数据分布的本质

### 第1讲 - 道生一·线性回归

**核心内容**：从最简单的线性模型开始
#### ✨ 本讲特色

> **"一元线性回归，掌握深度学习核心"**

本讲采用极简的一元线性回归模型 `y = kx + b`，通过精心设计的可视化方案，让抽象的深度学习概念变得触手可及：

- **🎯 以小见大**：仅用一个简单的线性模型，即可涵盖深度学习的核心概念和理论框架
- **📊 3D可视化优势**：由于损失函数是关于参数 `(k, b)` 的二元函数，可以绘制直观的3D曲面图和等高线图，这是高维神经网络无法做到的
- **🔍 全概念可视化**：在第一讲就将以下关键概念全部可视化呈现：
  - 残差的几何意义（真实值与预测值的垂直距离）
  - 不同损失函数的形态对比（绝对值损失的V型 vs 平方损失的抛物线）
  - 多数据点的损失叠加效应（多个凸函数相加仍为凸函数）
  - 梯度下降的优化路径（在3D曲面上的"下山"轨迹）
  - 三种梯度下降变体的收敛差异（SGD的震荡、BGD的平滑、Mini-batch的折中）
  - L1/L2正则化对参数空间的约束效果（菱形vs圆形等高线）
  - 动量法的加速机制（惯性效应的可视化）

- **💡 直观认知建立**：通过简单的线性回归让大家对神经网络形成直观认识，避免初学者一开始就陷入高维空间的抽象困境


#### 基础理论
- 线性回归基本概念
- 前向传播（预测）与反向传播（误差修正）
- 损失函数详解：
  - 残差绝对值损失
  - 残差平方损失（MSE）
  - 均方误差损失

#### 优化方法
- 梯度下降法核心思想
- 链式求导法则
- 三种梯度下降变体：
  - 随机梯度下降（SGD）
  - 批量梯度下降（BGD）
  - 小批量梯度下降（Mini-batch GD）

#### 正则化技术
- L1正则化
- L2正则化

#### 优化方法
- 动量法优化

### 第2讲 - 一生二·二分类

**核心内容**：从回归到分类的跨越

#### 感知器模型
- 符号函数激活
- 权重更新规则
- 几何直觉解释

#### 逻辑回归
- Sigmoid激活函数
- 交叉熵损失函数
- 梯度推导与参数更新

#### 激活函数对比
- Sigmoid函数及其导数特性
- Tanh函数及其优势
- ReLU函数与稀疏性
- 各激活函数的适用场景

### 第3讲 - 二生三·三分类

**核心内容**：从二分类到多分类的扩展

#### Softmax回归
- 从Sigmoid到Softmax的自然过渡
- 多类别概率建模
- 交叉熵损失的推广

#### 度量学习
- 余弦相似度的几何起源
- 向量空间中的距离度量
- 超平面与决策边界

#### 分类策略
- 一对多（One-vs-Rest）
- 多对多策略
- 决策边界的可视化

### 第4讲 - 三生万物·加一层与加多层

**核心内容**：深度神经网络的构建

#### 从浅到深
- 单层网络的局限性（XOR问题）
- 升维思想：从标量到向量再到矩阵
- 隐藏层的作用与意义

#### 基本门电路类比
- 与门、或门、非门的哲学含义
- 异或问题的非线性本质
- 神经网络的通用近似能力

#### 网络架构
- 全连接层设计
- 深度 vs 宽度
- 万能近似定理的直观理解

## 🚀 快速开始

### 环境配置

1. **安装Python环境**（推荐Python 3.8+）

2. **安装依赖包**
```
bash
pip install numpy matplotlib torch jupyter
```
3. **启动Jupyter Notebook**
```
bash
jupyter notebook
```
4. **按顺序学习各个章节**
   - 建议从第0章开始，循序渐进
   - 每个Notebook都可独立运行，包含完整代码和可视化

### 学习建议

1. **前置知识准备**
   - 如果数学基础薄弱，先学习`前置知识`文件夹中的内容
   - 重点掌握：导数、梯度、概率论基础

2. **实践为主**
   - 不要只看代码，要亲手运行并修改参数
   - 观察不同参数对模型的影响

3. **理解优先**
   - 重视每个概念的数学直觉
   - 结合可视化图表理解抽象公式
